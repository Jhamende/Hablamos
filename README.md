# Hablamos

Application Android native pour apprendre l'espagnol à partir de situations pratiques.

## Première version

- Interface Kotlin + Jetpack Compose
- Leçons thématiques en français et en espagnol
- Prononciation avec la synthèse vocale espagnole du téléphone
- Quiz interactif
- Progression de session
- Design Material 3

## Ouvrir le projet

1. Cloner ce dépôt.
2. Ouvrir le dossier dans Android Studio.
3. Laisser Gradle synchroniser les dépendances.
4. Lancer l'application sur un appareil ou un émulateur Android 8.0 ou supérieur.

Le projet utilise Java 17, Android Gradle Plugin 8.7.3, Kotlin 2.1.0 et compile avec le SDK Android 35.
