# Avatars générés Hablamos

Les fichiers `.webp.b64` contiennent des WebP encodés en Base64 afin de rester compatibles avec le connecteur de publication. `GeneratedAvatar.kt` les décode en mémoire au premier affichage.

- Paco : grammaire
- Mia : conversation
- Pepe : expressions
- Alba : culture

Ces ressources remplacent les anciens dessins Canvas dans les écrans V6 concernés.
